# Mon blog

Généré avec [Pelican](https://docs.getpelican.com/en/stable/index.html).

Thème `Blue Penguin` modifié manuellement pour ajouter des balises méta entre autres.

## Workflow

* écrire l'article dans content
* tester la génération avec `uv run make devserver`
* générer la version finale avec `uv run make publish`
* déployer le contenu généré sur 5apps
